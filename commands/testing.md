---
description: Create tests for the project
---
Create tests for the projects componentes, hooks, endpoints, uitils and scripts, to ensure that the code is working as expected and to catch any potential bugs early on. This can include unit tests, integration tests, and end-to-end tests. Use a testing framework such as Vitest, Jest and react-testing-library. Make sure to cover all critical functionalities and edge cases in your tests. Regularly run your tests during development to maintain code quality and reliability.
