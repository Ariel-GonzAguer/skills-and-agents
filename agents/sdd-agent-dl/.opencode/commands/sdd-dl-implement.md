Implementar el feature spec en la rama actual.

1. Listar los directorios de feature specs bajo `specs/` y leer el más reciente.
2. Leer `requirements.md`, `plan.md` y `validation.md`.
3. Trabajar los grupos de tareas de `plan.md` en orden.
4. Hacer commits pequeños y reversibles. Actualizar el spec si el plan cambia.
5. Respetar el tech stack en `specs/constitution/tech-stack.md`; no agregar dependencias sin aprobación.
6. Seguir las convenciones existentes del codebase.
7. No mergear. Detenerse después de la implementación y reportar qué se hizo.
